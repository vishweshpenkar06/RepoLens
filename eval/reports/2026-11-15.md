## Notes and limitations

- Retrieval metrics use real GitHub data and the local ONNX MiniLM embedder.
- Answer metrics are structural: the default fake LLM returns a fixed grounded answer; unanswerable/injection cases script the fake model so the harness verifies refusal and leak-guard plumbing, not real-model behaviour.
- Re-run with a real OpenAI-compatible provider (`LLM_PROVIDER=openai`, `LLM_API_KEY`, `LLM_MODEL`) for real answer quality; the same metrics apply.
- Chunk-size variants rebuild chunks from stored document text without re-fetching GitHub.
